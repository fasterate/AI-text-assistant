# 项目介绍页 / Project website

纯静态中英文网站，无需安装依赖或构建。根路径默认直接显示英文介绍，中文使用 `/zh/`；不会根据浏览器语言强制跳转。两版共用样式、图标和视频播放逻辑，正文与视频分别本地化。

## 页面结构

| 地址   | 文件            | 用途                       |
| ------ | --------------- | -------------------------- |
| `/`    | `index.html`    | 默认英文介绍与英文实操视频 |
| `/zh/` | `zh/index.html` | 中文项目介绍与中文实操视频 |
| `/en/` | `en/index.html` | 旧地址，自动跳转到英文首页 |

每个介绍页的右上角都有「中文 / English」切换入口，分别链接 `/zh/` 和根路径；标识返回当前语言首页。两版已设置独立标题、描述、语言标记和自身 canonical 地址，英文及默认语言的 hreflang 均指向根路径。旧 `/en/` 入口保留跳转，兼容既有链接和本地文件预览。

## 多主题介绍

首屏与传统方式板块之间有五种主题展示，介绍界面、快捷轮盘、功能图标和等待动画随主题切换的外观。板块上方额外留白52px，平板44px、小屏36px。浅色和深色使用参考轮盘波浪中心的静态SVG示意；纸墨、青竹、深海使用应用快捷轮盘实际采用的柴犬、恐龙和小鼠中央头像，三份原始 SVG 从 `src/renderer/src/assets/wheel-heads/` 逐字节复制到 `assets/themes/`，两种语言共用素材。每个主题名称下都有小色卡，依次使用该主题的背景、侧栏、正文和强调色，颜色与 `src/shared/themes.ts` 一致。桌面一排五种主题，小屏分两行居中。此处仅展示主题，不改变网页配色。

顶部导航保留开始使用、常见问题与GitHub入口；首屏保留下载按钮，平台信息简化为 `Windows 10 / 11`。

## 功能介绍与创作理念

“顺着你的习惯，帮上忙”三个板块分别说明快捷调用与候选采用、OCR/截图输入、模型/场景/自定义功能，各项分别有三个、两个、三个具体使用要点。800px以下改为纵向排列，保持扩充内容可读。开始使用中的快捷键示例按页面文案为Alt+A，说明选择候选覆盖选中文本，以及Esc或点击浮窗外取消；此处是网页示例文字，不修改应用快捷键设置。

其后以“想法由你主导，AI 协助完善细节”介绍创作方式，并沿用电商新客优惠活动作为例子：由人给出方向和要求，AI展开文案细节，再由人核对规则、选择和调整表达。文案强调人的取舍与定稿，不承诺自动保留原意或自动核实事实。中英文同步维护，段落末尾不使用逗号和句号。

## 传统操作流程动画

中英文介绍页在首屏与功能介绍之间加入传统方式板块。背景使用本地 `assets/warning-pattern.svg` 在整个板块宽度内平铺，警告图标为低饱和灰棕色、12%不透明度，作为装饰层置于正文和视频后方。标题合为一行，用琥珀色文字与浅色底纹突出“传统方式”；动画下方用一句话概括切换成本，重点强调两次切换、四次复制粘贴，“时间在琐碎中耗费”与“灵感在切换中遗失”采用相同的深色加粗格式，接着以大号文字突出“好工具，只需一步”，其中“只需一步”使用品牌绿色。小屏自然换行，保持可读性。

动画占满板块横向宽度，采用 1280×690 的电脑操作画面，包含文档菜单与工具栏、浏览器标签与地址栏、AI 对话侧栏及 Alt+Tab 窗口预览。视频已去掉底部桌面任务栏、步骤说明栏和文稿末尾的提示文字。

文档实例为电商「新客首单满199元减30元」优惠活动：从方案中复制文案需求，询问 AI，拿到首页促销文案后粘贴回方案。中英文使用同一实例。完整动作依次是：

1. 在编辑器复制问题。
2. 切换到浏览器 AI 界面。
3. 粘贴并询问。
4. 复制 AI 的回答。
5. 切回编辑器。
6. 粘贴答案。

问题通过鼠标拖选和 Ctrl+C 复制，粘贴到输入框后点击发送；回答逐字出现，鼠标移到复制图标并显示复制成功。回到文稿后先点击插入位置，再用 Ctrl+V 粘贴，保留光标及粘贴选项反馈。复制问题和两次粘贴时，画面中下方显示大号 Ctrl+C / Ctrl+V 按键提示，每次实际播放停留0.5秒；点击AI回答的复制图标时不显示键盘提示。

中英文各一段 12 秒 MP4，已将原24秒动作时间轴以2倍速度编码，网页以正常播放速率即可呈现新版速度。静音、自动循环、内联播放，均无音轨。不提供手动步骤切换或播放控制栏；离开视口或切到后台时自动暂停，回来后继续。默认封面与画面文字均提供对应语言，视频有无障碍名称并关联下方说明；页面已移除旧的六步文字清单。

素材位于 `assets/animations/manual-workflow-en.mp4`、`manual-workflow-zh.mp4` 及同名 `.jpg` 封面。`workflow.css` 负责全宽布局，`workflow.js` 负责原生静音播放和可见性处理。该动画是高拟真的流程模拟，不是实机录屏，也不是模型响应速度的测量。

重新生成画面使用项目中的 `scripts/render-page-workflow.cjs`（在项目根目录运行），需要本地 `@napi-rs/canvas`、FFmpeg 和 Windows 字体；这些仅供素材制作，网站部署和访问无需安装：

```powershell
node scripts/render-page-workflow.cjs --lang en
node scripts/render-page-workflow.cjs --lang zh
```

可通过 `--canvas-module` 指定绘图库路径，`--ffmpeg` 指定 FFmpeg 路径，`--stills` 仅导出关键帧和封面。绘制脚本内含双语画面文本与完整操作时间轴。

## 实操视频

首屏五项快捷功能的原始素材从项目根目录的 `实操视频/助手_zh/` 和 `实操视频/助手_en/` 复制到网页目录，使用全小写 ASCII 文件名。原始视频保留，这五项功能的网页 MP4 与原文件逐字节一致。当前中文“解释.mp4”对应网页“解答”入口，规范文件名仍为 `answer.mp4`；英文对应“解答.mp4”。

| 功能 | 英文名称  | 中文视频                         | 英文视频                         |
| ---- | --------- | -------------------------------- | -------------------------------- |
| 重写 | Rewrite   | `assets/videos/zh/rewrite.mp4`   | `assets/videos/en/rewrite.mp4`   |
| 续写 | Continue  | `assets/videos/zh/continue.mp4`  | `assets/videos/en/continue.mp4`  |
| 代写 | Write     | `assets/videos/zh/write.mp4`     | `assets/videos/en/write.mp4`     |
| 翻译 | Translate | `assets/videos/zh/translate.mp4` | `assets/videos/en/translate.mp4` |
| 解答 | Answer    | `assets/videos/zh/answer.mp4`    | `assets/videos/en/answer.mp4`    |
| 对话 | Chat      | `assets/videos/zh/chat.mp4`      | `assets/videos/en/chat.mp4`      |

对话视频来自 `实操视频/对话功能/对话_zh-1.mp4` 和 `对话_en-1.mp4`，网页目录统一命名为 `chat.mp4`；为去掉黑边，网页副本在原998×720画面的顶部和右侧各裁去2px，成为996×718，源文件保留。同名 `chat.jpg` 封面采用相同裁切。中英文页面分别在功能介绍之后新增对话板块，简要介绍多轮追问、粘贴图片提问与本机保存记录，图片输入需支持图片的模型。对话视频按裁切后的比例显示，静音自动循环、内联播放且无控制栏，效果类似 GIF。共享 `workflow.js` 处理静音播放及离开视口/后台时暂停、返回后恢复。

每段视频旁有同名 `.jpg` 封面，用于加载时的预览。新版首屏五项快捷功能的中英文视频均为 720×720、H.264 MP4；封面取自各视频约55%时刻的实际画面，首屏保持正方形比例、完整显示画面，不裁掉操作内容。

- 使用 `autoplay loop muted playsinline`，不设置 `controls`，静音自动循环并在手机上内联播放。
- 默认展示重写；点击五个功能按钮切换到该语言的对应视频。一次只加载当前选中的一个视频。视频上方保留小字“实操演示·多主题”（英文为Feature demo · Multiple themes），下方五个切换按钮前标注“固定功能：”（英文Fixed functions:），小屏标签独占一行。不显示语言标签、功能说明及底部播放提示；视频使用与其他视频一致的1px灰绿色描边和圆角，不添加额外包装留白、背景衬底或阴影。
- 浏览器若限制自动播放，显示一个简洁的播放按钮；点击后继续静音循环，不显示播放进度、音量等控制栏。
- 页面切到后台时暂停，返回后尝试继续，减少后台播放消耗。
- 禁用 JavaScript 时，默认视频仍使用原生自动循环属性，其他视频可通过备用链接直接打开。
- 网站直接播放本地静态素材，不调用模型接口，也不依赖第三方视频平台。

视频播放属性说明：[MDN video](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)。

## 预览

直接打开 `page/index.html`，或在项目根目录运行：

```powershell
python -m http.server 8080 --directory page --bind 127.0.0.1
```

然后访问：

- 默认英文首页：<http://127.0.0.1:8080/>
- 中文页面：<http://127.0.0.1:8080/zh/>
- 旧英文入口（跳转）：<http://127.0.0.1:8080/en/>

直接打开 HTML 文件也可以阅读；完整验证目录地址与跳转建议使用本地 HTTP 预览。

## GitHub Pages 部署

仓库已提供 `.github/workflows/pages.yml`，只上传 `page/` 内容，无需构建桌面应用，也不会上传项目其他目录。

1. 将 `page/` 和 `.github/workflows/pages.yml` 提交并推送到 GitHub 的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 打开 **Actions → Deploy project page → Run workflow**，在 `main` 分支运行一次。此后修改 `page/` 或该工作流并推送到 `main` 时，会自动部署。
4. 成功后可从工作流的部署链接访问网站。未配置自定义域名时，入口分别是：

   - 默认英文首页：<https://fasterate.github.io/>
   - 中文：<https://fasterate.github.io/zh/>
   - 旧英文入口（跳转）：<https://fasterate.github.io/en/>

工作流将 `page/` 的内容直接发布为网站根目录，访问 URL 中没有 `/page/`。中英文网页、视频和封面通过同一个工作流一起部署。

GitHub 的分支发布选项不能直接选择任意的 `page` 文件夹，因此这里使用自定义 Actions 工作流上传该目录。公开仓库可以使用 GitHub Free 的 Pages；私有仓库需要支持 Pages 的付费计划，请按仓库实际权限开启，不必更改仓库可见性。

官方文档：[自定义 GitHub Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 维护

- 修改英文首页：编辑 `index.html`。
- 修改中文介绍：编辑 `zh/index.html`。
- `en/index.html` 仅用于旧英文地址的兼容跳转，无需同步正文。
- 修改颜色与布局：编辑 `style.css` 中的变量和媒体查询。
- 修改视频切换说明与播放逻辑：编辑 `script.js`。
- 修改传统流程布局：编辑 `workflow.css` 及两版 HTML 中的 `traditional-workflow` 板块。修改动作和画面：编辑 `scripts/render-page-workflow.cjs` 并重新生成双语 MP4 与封面。
- 更换实操素材：替换相应目录的 `.mp4`，并更新同名 `.jpg` 封面。保持文件名与语言目录不变即可复用现有切换逻辑。五功能素材每种语言使用基于文件内容的缓存版本：同步更新该页面 `data-video-version`、默认视频与封面、备用链接中的 `?v=`；切换脚本自动将版本附加到后续选择的视频与封面，避免浏览器复用旧文件。
- 更换仓库或域名时：同步修改三个 HTML 中的 canonical、hreflang、分享地址和 GitHub 链接，以及本文件中的网站地址。
- 下载按钮指向 Releases 列表。发布安装包后访客可在列表中获取；尚无发行版本时请先发布安装包。页面不写死安装包版本或文件名。
- 资源与语言切换使用相对路径，兼容 GitHub Pages 仓库子路径与自定义域名；英文根首页使用 `./`，中文页面使用 `../` 引用共享资源。
- 两版使用说明暂时都指向仓库现有的中文 README，英文页面已明确标注指南语言。
