A few things to know

Before you get started

Which models can I connect?

The app supports OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Google Generative AI protocols. Configure the matching service URL, API key, and model name. Image chat and direct screenshot input need a model that supports images

Where are my text, images, and keys stored?

Settings and chat history are stored on your device. API keys are encrypted using Windows system protection. When you use a model, the relevant text or images are sent to your chosen model service. Screenshot OCR runs locally before the extracted text is sent. Clearing chat also deletes its locally saved text and images
