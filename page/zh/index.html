你可能还想知道

开始之前，几个小问题

可以连接哪些模型？

支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Generative AI 协议。填写对应的接口地址、密钥和模型名即可配置；图片对话与截图直传需要选择支持图片的模型

文字、图片和密钥会保存在哪里？

设置与对话记录保存在本机，API Key 使用 Windows 系统保护能力加密。处理内容时，文字或图片会发送到你选择的模型服务；截图 OCR 先在本地识别，再发送提取的文字。清空对话会同时删除本机保存的聊天文字和图片
