1. 数据控制者

经营者及就我们直接处理的信息承担责任的个人信息处理者为罗江（Luo Jiang），位于中国湖北，以个人开发者身份经营，无注册公司。隐私与客服邮箱均为 lj188640@gmail.com。我们未指定专门的数据保护负责人，隐私请求由经营者处理。

2. 处理的信息与来源

本机信息。 Windows 软件在您的设备保存模型配置、提示词、对话文字及对话中的图片等资料；API Key 在本机使用 Windows 系统保护能力加密保存。对话、图片及普通配置并非全部加密。软件没有我们运营的注册账户、登录或云同步后台，常规使用中这些本机资料不会自动上传给经营者。

模型请求。 当您发起生成或对话时，相关文字、图片以及本机尚未删除、已完成的历史对话可能作为上下文发送至您配置的模型接口，并经过您配置的代理（如有）。请求包含鉴权所需的 API Key 等信息；连接测试也会向所选接口发送短测试指令和鉴权信息。截图文字识别在本机进行；您选择发送图片时，图片会发送给模型服务。读取选区可能临时使用剪贴板并尝试恢复，生成结果也可按您的操作写入剪贴板。

购买与支持。 您购买或联系支持时，我们处理您提供的邮箱、订单编号、金额、币种、支付状态，以及邮件、反馈和您主动附上的资料。不必向客服提供完整卡号、安全码、API Key 或无关的敏感内容。官网托管服务还可能记录 IP 地址等访问信息，见第 4 条。

3. 使用目的与依据

我们仅为履行软件购买与交付、核验订单、处理账单问题和客户支持而使用相关信息；为必要的安全、故障排查及争议处理使用最少必要信息；并在法律要求时履行记录保存等义务。适用法律认可时，依据分别为履行合同、必要且合理的合法利益或法定义务；法律要求同意的处理，以依法取得的有效同意为依据。我们不会仅凭您购买软件推定同意营销，不会出售个人信息或将其用于定向广告。

4. Cookie、网站与托管日志

官网为 GitHub Pages 静态网站，未自行设置 Cookie、浏览器本地存储、访问分析或广告追踪工具。GitHub 为托管、安全及服务运行可能记录访客 IP 地址等技术信息，并按其自身政策处理。详情见 GitHub 隐私声明。外部收银台、下载站点或模型服务可能使用自己的 Cookie，相关规则以其页面说明为准。

5. 共享与服务提供方

我们仅在提供相关服务、履行法律义务、处理争议，或取得依法要求的同意时，向必要接收方披露必要信息。

  • Waffo Pancake： 处理结账、支付及相关订单事务。完整卡号、安全码由支付服务处理，不由我们接收或保存；请查阅收银台说明及 Waffo 隐私政策。
  • GitHub： 提供网站托管及相关基础设施，政策链接见第 4 条。
  • Google / Gmail： 提供客服邮箱服务，邮件及附件由其服务处理。请查阅 Google 隐私政策。
  • 您选择的模型和代理服务： 接收您主动发起的请求，处理范围取决于您的配置及其政策。

我们不出售个人信息，也不向广告商提供个人信息用于跨情境行为广告。依法披露或业务经营主体发生变更时，我们将遵守适用的通知、目的限制及保护要求。

6. 数据安全

官网使用 HTTPS，API Key 在本机加密保存；模型接口及代理可由您自行配置，通信安全取决于相应地址和服务，请优先使用可信的 HTTPS 接口。我们按必要范围访问订单和客服资料。请保护设备、邮箱和密钥，避免在对话或工单中提供不必要的敏感信息。本机聊天与图片不享有全部加密保护。发生个人信息安全事件时，我们将依法采取处置措施，并按适用要求通知受影响用户及主管机关。

8. 您的权利

在适用法律规定的范围内，您可请求了解、访问或复制我们处理的个人信息，更正不准确的信息，删除信息，限制或反对处理，在适用时获得可携带的数据，并撤回基于同意的处理授权。撤回不影响撤回前依法进行的处理。请向隐私邮箱提出请求；我们可能进行合理身份核验，并在适用法律规定的期限内答复。我们没有账户注销流程；本机数据可自行管理，第三方持有的数据可联系对应提供方。您可向有管辖权的数据保护或其他主管机关投诉。

9. 服务通知与营销

我们可能通过您为订单或支持提供的邮箱发送交付、账单、安全及重要政策通知，这些属于相关服务沟通。我们目前不运营营销邮件订阅或广告追踪系统。未来若开展需要同意的营销，将另行取得同意，并提供可实际使用的退订方式；购买软件不等于订阅营销。

10. 跨境处理

GitHub、Google、Waffo 及您选择的模型或代理服务可能在您所在国家或地区之外处理数据，具体地点与安排以相应服务的政策为准。请在配置模型及提交资料前了解这些安排。对于由我们决定并依法受跨境规则约束的处理，我们将履行适用的告知、同意及其他保障要求；需要单独同意时，将针对具体处理依法另行取得。

11. 未成年人

未成年人可在监护人同意并指导下使用本产品；购买应具有相应民事行为能力或获得监护人授权。我们不会因使用软件而要求提交身份证明或出生日期。涉及中国不满 14 周岁儿童的个人信息，依法需取得监护人同意并适用儿童及敏感个人信息保护要求；其他地区有更严格规定时，遵守当地要求。请监护人协助选择适龄的模型服务并避免提交不必要的个人信息；如发现未经必要同意提交儿童信息，请联系我们核查、删除或依法采取其他措施。

12. 第三方模型与链接

您自行选择模型接口、代理及下载或支付等外部服务，其独立条款和隐私政策适用。模型提供方是否保留请求、用于改进或训练模型、提供删除选项，取决于其具体政策和设置；我们不作统一保证。发送前请核对接口地址及历史上下文，确认有权分享相关文字、图片和他人信息。本政策说明我们的处理活动，不替代第三方必须提供的隐私披露。

13. 政策变更

更新时，我们会修改本页的版本和日期，并保留带生效日期的历史版本。涉及处理目的、数据类别或权利等重大变化时，将在网站说明，并在可行且与您相关时通过订单或支持邮箱通知；法律要求事先告知或重新取得同意的，依法执行。更新不会使未经合法依据的既有处理自动获得授权。
